# Database

Cloudflare D1 (SQLite dialect). Local dev DB lives in `backend/.wrangler/state/v3/d1`.

## Migration policy — READ FIRST
- **Migrations are append-only.** Never edit an applied migration; add `00NN_*.sql` in
  `backend/migrations/` and describe it here.
- Applied migrations are tracked in the `d1_migrations` table by wrangler.
- CI applies remote migrations before deploy (`wrangler d1 migrations apply --remote`) — this is
  safe and incremental; it never resets data.
- **NEVER** run destructive SQL against any shared/remote database.

## Seed safety
- `db/seed.sql` is generated by `scripts/generate-seed.mjs`.
- Generated seed uses **INSERT OR IGNORE with deterministic IDs only** — zero DELETE/DROP.
- Demo rows use high ID offsets (900000+) so they can never collide with real auto-increment IDs.
- Re-running on a populated DB changes nothing.

## Conventions
- Money: REAL rounded to 2dp at write time (`r2`).
- Timestamps: TEXT ISO `YYYY-MM-DD HH:MM:SS` UTC.
- FKs declared with ON DELETE CASCADE where child rows are owned.
